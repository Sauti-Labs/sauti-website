# design/

This directory holds engineering-relevant design artifacts and
documentation - reference material a developer needs to implement
something correctly.

## What belongs here

- UX flow documentation
- Design decisions and their rationale
- Design-system documentation (once one exists)
- Approved visual references a developer needs while implementing

## What does NOT belong here

- Raw Figma exports with no lasting reference value
- Random or work-in-progress screenshots
- Editable design source files - Figma (or equivalent) remains the source
  of truth for editable design work; this directory holds engineering-
  relevant artifacts and documentation derived from it, not the editable
  files themselves

## Structure

This directory is intentionally flat for now. No design artifacts exist
yet. Subdirectories (e.g. user-flows/, wireframes/, mockups/, decisions/)
will be introduced when a clear recurring categorization emerges that
materially improves discoverability and navigation - see
docs/architecture.md for the full reasoning.
